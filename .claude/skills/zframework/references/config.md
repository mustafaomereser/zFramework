# zFramework Configuration Reference

Every file under `config/`, plus `database/connections.php`. Read with `config('app.title')`
(dot notation) or `Config::framework('view.caching')`.

`config/crypt.php` is gitignored and generated by `php terminal security key [--regen]` — never
commit it, never hand-write it.

---

## `config/app.php` — what the application is

```php
// 'debug', 'error', 'force-https', 'x-powered-by' and 'pagination' moved to config/framework.php
// (each still read from here if an application has not moved it)
'lang'         => 'tr',      // fallback when the browser's language is not in config/languages.php
'title'        => 'zFramework',
'public'       => 'public_html',
'version'      => '1.0.0',
// (pagination moved to framework.php)
```

## `config/framework.php` — how the framework behaves

```php
'view' => [
    'caching' => true,       // off while writing templates; on in production
    'minify'  => true,
],
'route' => [
    'caching'    => true,    // serve from the cache built by `php terminal route cache`
    'auto-check' => false,   // notice an edited route file (one stat per file per request)
],
'log' => [
    'enabled' => true,
    'level'   => 'debug',    // debug | info | warning | error
    'days'    => 14,         // day files kept; 0 keeps everything
],
'throttle' => [          // only the fallback - the limit belongs on the route group,
    'enabled' => true,   // Route::pre('/api')->throttle(120)->group(...)
    'limit'   => 60,     // false here turns every limit off, wherever declared
    'window'  => 60,     // seconds
    'by'      => 'ip',   // ip | token
    'block'   => 0,      // seconds to refuse outright once the limit is passed
],
'debug'        => true,        // false in production. The one switch: error page, query log, analyzer,
                               //   stack-trace args, unminified compile. Read it with Config::debug().
'force-https'  => false,       // redirect http → https; decided in bootstrap before anything runs
'x-powered-by' => true,        // false hides `X-Powered-By: zFramework vX.Y.Z`
'error' => [
    'logging'   => true,     // a self-contained HTML report per error under error_logs/
    'keep_days' => 14,       // how long one is kept; 0 keeps everything
    'stream'    => false,    // false | 'error_log' | 'stderr' | 'syslog' — one-line summary
    'mask'      => [],       // key names shown as •••••• — empty means nothing is hidden;
                             //   substring match on the key, everywhere in the report
    'previous'  => 10,       // earlier reports the page links to
    'callback'  => fn($log_path, $log) => ...,   // dies on CLI unless ZF_WORKER is defined
],
'trusted-proxies' => [],       // addresses ip() will read a forwarded header from.
                               // Empty trusts none: REMOTE_ADDR and nothing else.
'session' => [
    'driver'         => 'file',   // file | redis (redis for multi-server)
    'gc_probability' => 1,        // ignored by the redis driver
],
'response' => [
    'ajax'       => ['include-alerts' => true],   // attach pending alerts to every JSON response
    'cache-ttl'  => 600,     // what Page::cache() uses when called with no number
    'page-cache' => true,    // the server-side page store; a kill switch, not an opt-in
],
'cache' => [
    'apcu' => true,          // keep the table schema in shared memory instead of re-reading
                             // zFramework/storage/db/<db>/scheme.json per connection
],
'redis' => [
    'enabled'  => false,     // nothing else here is read while false
    'host'     => '127.0.0.1',
    'port'     => 6379,
    'password' => null,
    'timeout'  => 1.5,
    'database' => ['cache' => 0, 'session' => 1, 'queue' => 2],   // separate, so a cache
                                                                  // flush does not take sessions
    'prefix'   => 'zf:',
    'l1_ttl'   => 5,         // seconds a value may be served from process memory before
                             // re-asking redis; higher is faster, servers may briefly disagree
],
'profiling' => [
    'enabled'      => false,
    'rate'         => 1,        // 0.05 = one request in twenty
    'keep'         => 200,      // stop recording past this; old records are the baseline
    'queryAnalyze' => false,    // true | false | a sampling fraction; needs debug
    'queryStore'   => 'file',   // 'file' → analysis/queries/*.jsonl | 'table' → system_db_collector
],
```

A closure route cannot be cached, and **one of them keeps the whole table out**.
`php terminal route cache` names the offenders.

The cache also stores urls as literal strings, so a prefix built from request state — a
locale, a tenant — is frozen at build time. A few of those go in `route/dynamic/`; if most of
the routing is dynamic, set `caching => false` and keep one route file instead of maintaining
the split. `references/routing.md` has the detail.

## `config/mail.php`

```php
'sending'  => true,          // master switch
'queue'    => false,         // true → Mail::send() enqueues and returns "queued", not "delivered".
                             // Needs redis; without it everything sends inline. sendNow() always bypasses.
'debug'    => false,
'SMTPAuth' => true,
'security' => 'ssl',         // ssl | tls
'mail'     => 'mail.server.com',
'port'     => 443,
'username' => 'test',
'password' => 'test',
'subject'  => '',
'from'     => ['First Last', 'from@example.com'],
'reply'    => ['First Last', 'replyto@example.com'],
```
Override per send with `Mail::set([...])`.

## `config/model.php`

```php
'consts' => [
    'created_at' => 'created_at',
    'updated_at' => 'updated_at',
    'deleted_at' => 'deleted_at',
],
'deleted_at_type' => 'date',   // 'date' | 'bool'
```
`'bool'` inverts the sense on purpose: a column like `status` where 1 means "not deleted".
Per-model override: the `$created_at` / `$updated_at` / `$deleted_at` properties (set one to
`null` to disable auto-timestamping).

## `config/languages.php`

```php
return ['tr' => 'Türkçe', 'en' => 'English'];
```
Each key needs a matching `resource/lang/{key}/` directory.

## `config/push-notification.php`

```php
'default'      => 'app',           // application used when a send does not name one
'queue'        => true,            // ignored without redis
'queue_name'   => 'push-notification',   // its own queue, so a broadcast does not block signup mail
'ttl'          => 2419200,         // 28 days the push service holds it for an offline device; 0 = now or drop
'urgency'      => 'normal',        // very-low | low | normal | high (all-high gets you throttled)
'max_failures' => 10,              // drop a subscription after N consecutive failures.
                                   // 404/410 are deleted immediately without counting. 0 disables.
'hosts'        => [],              // allowed push hostnames as suffixes; empty = any public https host.
                                   // Endpoints resolving to a private address are refused either way.
'apps' => [
    'app' => [
        'channel'     => 'webpush',
        'subject'     => 'mailto:admin@example.com',   // required by RFC 8292
        'public_key'  => '',        // php terminal push-notification keys app
        'private_key' => '',        // treat as a credential; keep it out of the repository
        'defaults'    => ['icon' => '...', 'badge' => '...', 'url' => '/'],
    ],
],
```
A subscription belongs to an **application key**, not to the installation — one codebase can serve
several products and none can reach another's subscribers. Changing a key pair invalidates every
subscription taken with the old one.

## `config/crypt.php`

```php
return ['key' => '...', 'salt' => '...'];
```
Generated, gitignored. `php terminal security key --regen` on a fresh install. Regenerating
invalidates everything `Crypter` produced: api tokens in cookies, obfuscated cookie values.

## `database/connections.php`

```php
return [
    'local' => ['mysql:host=127.0.0.1;port=3306;dbname=z_framework;charset=utf8mb4', 'root', '', 'options' => [
        [\PDO::ATTR_ERRMODE, \PDO::ERRMODE_EXCEPTION],
        [\PDO::ATTR_EMULATE_PREPARES, true],   // needed for lastInsertId
        [\PDO::ATTR_PERSISTENT, true],
        [\PDO::ATTR_TIMEOUT, 2],
    ]],
];
```

The first entry is the default; a model picks another with `public $db = 'name'`, a migration with
`static $db`.

- **`ATTR_PERSISTENT`**: reuses the connection instead of a handshake per request. Count first —
  one connection per FPM worker per entry stays open even while idle, so 50 workers × 5 tenants
  holds 250 against `max_connections`. `php terminal bench run` reports what it saves.
- **`ATTR_TIMEOUT`**: connect timeout only, a slow query is unaffected. Every request pays it in
  full before the 503. Lower it to 1 for a database on the same machine.
- **Write the host as an address, not a name.** `localhost` is tried over IPv6 first and then IPv4,
  which doubles the wait. Measured against a dead server: `127.0.0.1` 2 s, `localhost` 4 s,
  unreachable IP 21 s.

Drivers: `mysql` and `sqlsrv` (`zFramework/Core/Facades/DB/Drivers/`).
